# Hi, I'm Erhan 👋

**Full-stack and mobile developer** building calm, privacy-first apps and the tooling that keeps AI-assisted development safe.

## What I work on

- **Mobile apps:** native iOS with Swift and SwiftUI, plus cross-platform work in Dart.
- **Family and child safety:** screen-time tools designed around trust, not covert monitoring.
- **Developer tooling:** shell and Python utilities, agent skills, and review workflows that falsify claims before they ship.
- **Security by default:** secret scanning on every commit, least-privilege keys, and OWASP-based checklists.

## How I build

- Open-source, permissively licensed building blocks (MIT, Apache-2.0, BSD).
- No telemetry, no tracking, and no dark patterns in billing or consent.
- Small, reversible changes with a test or check that proves each one.
- Accessibility (WCAG 2.2 AA) treated as a bug class, not a nice-to-have.
